보이스 텍스트 변환 개인정보처리방침

최종 업데이트: 2026년 10월 23일

'보이스 텍스트 변환'(이하 "앱")은 이용자의 개인정보를 소중히 여기며, 아래와 같이 개인정보처리방침을 안내합니다.

1. 수집하는 정보와 목적

정보언제어디로목적
녹음한 음성(오디오)텍스트 변환을 사용할 때Google Gemini API (이용자 본인의 API 키)음성을 텍스트로 변환
변환된 텍스트AI 요약·회의록·작업 항목·번역·제목 제안을 사용할 때Google Gemini API (이용자 본인의 API 키)AI 기능 제공
광고 ID (Android 광고 식별자)앱 사용 중Google AdMob광고 표시 및 광고 성과 측정
  • 텍스트 변환과 AI 기능은 이용자가 직접 입력한 본인의 Google Gemini API 키로 Google에 요청합니다. 개발자는 별도 서버를 운영하지 않으며, 녹음이나 텍스트를 받거나 저장하지 않습니다.
  • 설정에서 '자동 텍스트 변환'을 끄고 변환을 요청하지 않으면 녹음은 외부로 전송되지 않습니다.
  • Gemini API 무료 등급에서는 Google이 서비스 개선을 위해 전송된 데이터를 사용할 수 있습니다. 자세한 내용은 Google의 약관을 확인해 주세요: https://ai.google.dev/gemini-api/terms

2. 기기 안에서만 처리하는 정보 (외부 전송 없음)

  • 녹음 파일, 메모, 태그, 북마크, 변환된 텍스트: 이용자의 기기에 저장됩니다. 앱을 삭제하면 함께 삭제됩니다.
  • Gemini API 키: Android Keystore로 암호화해 기기에만 저장하며, Gemini 인증 외에는 사용하지 않습니다.
  • 캘린더 일정 제목: '캘린더로 녹음 이름 자동 지정'을 켠 경우에만, 녹음 시점의 일정 제목을 녹음 이름으로 쓰기 위해 기기 안에서 읽습니다. 외부로 전송하지 않습니다.
  • 백업·클라우드 업로드: 이용자가 직접 고른 위치(기기, Google Drive, OneDrive 등)에만 저장됩니다. 저장 위치의 개인정보 처리는 해당 서비스의 방침을 따릅니다.

6. 보안

외부 전송은 모두 암호화(HTTPS/TLS) 통신으로 이루어집니다.

7. 어린이 개인정보 보호

앱은 만 13세 미만 어린이를 대상으로 하지 않으며, 어린이의 개인정보를 의도적으로 수집하지 않습니다.

Voice to Text Privacy Policy

Last updated: October 23, 2026

1. Information we collect

DataWhenSent toPurpose
Recorded audioWhen you use transcriptionGoogle Gemini API (your own API key)Speech-to-text
Transcribed textWhen you use AI summary, minutes, action items, translation or title suggestionsGoogle Gemini API (your own API key)AI features
Advertising IDWhile using the appGoogle AdMobShowing ads and measuring ad performance
  • Transcription and AI features call Google with your own Gemini API key. The developer runs no server and never receives or stores your recordings or text.
  • If automatic transcription is off and you do not request it, recordings never leave your device.
  • On the free Gemini tier, Google may use submitted data to improve its services: https://ai.google.dev/gemini-api/terms

2. Processed only on your device

  • Recordings, memos, tags, bookmarks and transcripts are stored on your device and are removed when you uninstall the app.
  • Your Gemini API key is encrypted with Android Keystore and used only for Gemini authentication.
  • Calendar event titles are read on the device only when "name recordings from calendar" is enabled, and are never transmitted.
  • Backups and cloud uploads go only to the location you choose.

3. Third-party services

  • Google Gemini API — https://policies.google.com/privacy
  • Google AdMob — https://policies.google.com/technologies/ads

4. Deletion

Delete recordings and text in the app at any time. Reset your advertising ID in device settings. For other requests, email us.

5. Children

The app is not directed at children under 13.
